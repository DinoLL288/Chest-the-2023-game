# Chest the 2023 Game

A playable browser version of Chest, a custom chess/checkers-style board game with HP, special moves, staffs, charge attacks, shields, revives, and colour abilities.

## Play online

After GitHub Pages is enabled for this repository, the public link is:

https://dino288.github.io/Chest-the-2023-game/

## Multiplayer

Use **Host room** to make a room code, then send the copied room link to another player. The second player opens the link and joins the room. Multiplayer uses browser-to-browser WebRTC through PeerJS, so both players need an internet connection and a browser that supports WebRTC.

## Local play

Download this repository and open `index.html` in any modern browser.
